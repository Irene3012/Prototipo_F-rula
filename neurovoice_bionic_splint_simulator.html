Guía Completa: Supabase + GitHub para la Exposición

Paso a paso para desplegar y configurar este proyecto en clase

Paso 1: Configurar la Base de Datos en Supabase

  1. Entra en supabase.com y crea un proyecto gratuito.
  2. Ve al apartado SQL Editor y ejecuta el siguiente comando para crear la tabla de logs:
CREATE TABLE neurovoice_logs (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  pattern TEXT NOT NULL,
  phrase TEXT NOT NULL,
  created_at TIMESTAMPTZ DEFAULT now()
);

Paso 2: Subir el código a GitHub

Crea un repositorio en GitHub con el nombre neurovoice-bionic-splint y sube este archivo como index.html.

Activa GitHub Pages en la configuración del repositorio para que la web sea accesible mediante un enlace público al instante.
